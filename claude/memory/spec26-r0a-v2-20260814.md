Measure track / density-new. Spec `PAPER/Multistep-FB/specs/26-bfm-roadmap.md`
(R0a-v2 contract ~line 249), executed as spec 27 Q3. v1 was `6d5c4cc`.

**Why v2 existed.** R0a v1 injected duplicated `s'=s` rows and failed BY
INSTRUMENT: duplication changes the empirical kernel, so the exact successor
measure of the corrupted kernel drifts identically and all five converged tabular
arms sat on that curve. v2 holds the kernel fixed by applying multiplicity as a
sampling WEIGHT.

**Contract interpretation that matters.** The weight is keyed on the **dwell
STATE**, not on `s'==s` rows. A transition-keyed weight is algebraically
identical to v1 duplication in expectation and reproduces the same kernel
corruption. Two POSITIVE controls pin this (`test_positive_control_v1_row_
duplication_does_move_the_kernel`, `test_positive_control_transition_keyed_
weights_move_the_kernel`) alongside `test_empirical_kernel_byte_identical_across_
weights`. 59 tests pass. New files `scripts/synthetic/fork_dwell_v2.py`,
`run_fork_dwell_v2_study.py`, `tests/test_fork_dwell_v2.py`; v1 untouched.

**GATE P1-v2 = FAIL on both halves** (primary metric `margin_ratio`).

*Half A (separation under rank constraint) fails because the arms are DEAD, not
flat.* d2/d4 sit at margin_ratio ≈ .00-.06 at w=1 already (rank 2/4 vs the ~11
needed, plus aliasing), so there is no headroom for the intervention to act in;
unnorm slopes are indistinguishable from 0. ⚠ Their `flat_ratio` 14.7/20.8 is
EXACTLY the artifact the `unnorm_slope_nonzero` guard exists to reject — a ratio
of two near-zero slopes. Keep that guard prominent; it is good instrument design.
The task hardening overshot.

***Half B fails BACKWARDS, and that is the real result.*** The converged tabular
control was predicted null; instead `joint_unnorm` decays **1.036 → 0.705** with
the unnormalized CI excluding zero (normalized CI contains it). Every other
tabular arm sits at ≈1.0.

**★ MECHANISM.** The tabular fixed point is provably weight-invariant (the
byte-identity test), so the control's drift CANNOT be a fixed-point effect — it
is pure **optimization rate**. At w=20 the decision state receives ~0.1% of
draws; an unnormalized regression learns that row only from its own draws, while
the softmax-over-pool arms couple a starved row to well-sampled ones. **The
thesis's channel is SAMPLE STARVATION, not capacity.** It therefore needs
HEADROOM to be visible — which the converged column has and the rank-constrained
columns (dead at w=1) do not. That is why half A and half B fail together.

**⚠ THE LIMITATION TO CARRY INTO THE PAPER.** `feat_full` confirms the
separation is confined to the JOINT unnormalized critic (joint_unnorm .433→.158)
and **FB's own bilinear critic is FLAT (fb_unnorm .437→.417)**, with both
normalized arms ≥.95. So the effect is real but does NOT live in FB's
architecture. Any density-new claim resting on "FB's estimator is pathological
under dwell" is not supported by this synthetic in that form.

**Redesign direction (not yet contracted):** the constrained columns need enough
rank/budget to be alive at w=1 before the starvation channel can show, i.e. the
opposite of v2's hardening. Also: the control budget was raised 30k→100k BEFORE
the run because `joint_unnorm` was still improving at 30k and so was not
converged; `d8` was run but hard-excluded from the verdict.
