\section{Additional results}
\label{app:tables}

This appendix provides the detailed numbers behind the main-paper analyses: per-goal success, the exact terminal-outcome distribution, the full
state-support distances, the backward-embedding geometry probe, and the counterfactual value and representation-ranking analysis.
These results support the main empirical chain: aggregate success hides post-acquisition failures; state-support gaps broadly covary with performance, while weak value ranking persists for initial states drawn from the offline dataset; coarse cube-to-goal geometry is insufficient; and learned values
differ in how well they rank in-hand states by the agent's own eventual success.
Throughout this subsection, \emph{value} refers to the method-specific task-conditioned scalar used to rank states or actions.

\subsection{Counterfactual value and representation ranking}
\label{app:counterfactual_ranking}

The main value-ranking analysis uses an on-policy counterfactual label.
We reset the simulator to in-hand grasp states, roll out each agent's own policy, and label each state by whether that agent reaches the goal.
This directly tests whether the learned value ranks acquired-control states by eventual task success under the corresponding policy.
Because the labels are generated separately under each method's own policy, the analysis measures consistency with each method's own downstream outcomes rather than comparison against a single shared target.

We reset $200$ in-hand grasp states in the simulator and roll out each agent's own (flow) policy for $K=10$ independent continuations per grasp, labeling the grasp by the fraction that reaches the goal (the flow policy is stochastic, so a single rollout is a noisy draw). We report the learned value's rank-AUC against this success label, computed per goal, averaged across goals and across the method's flow-actor training seeds ($9$--$10$ seeds), together with the mean counterfactual success rate.}

Figure~\ref{fig:cf_ladder} compares the learned value with a supervised linear readout from the representation used to compute it.
This asks whether the representation contains linearly accessible information about the agent's own counterfactual success and whether the learned value
preserves that information in its ranking.
