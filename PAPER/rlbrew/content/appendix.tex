\section{Additional results}
\label{app:tables}

This appendix provides the detailed numbers behind the main-paper diagnostics: per-task success, the exact terminal-outcome distribution, the full dataset-support distances, the backward-embedding geometry probe, and the counterfactual value/representation-ranking analysis. 
These results support the main empirical chain: scalar success hides post-acquisition failures; state-space support covaries with performance but cannot explain ranking failures on states drawn from the dataset itself; coarse cube-goal geometry is insufficient; and learned values differ in how well they rank in-hand states by the agent's own future success.

\subsection{Counterfactual value and representation ranking}
\label{app:counterfactual_ranking}

The main value-quality diagnostic uses an on-policy counterfactual label. 
We reset the simulator to in-hand grasp states, roll out each agent's own policy, and label each state by whether that agent reaches the goal. 
This directly tests whether the value the policy follows ranks post-acquisition states by their eventual tail outcome.

We reset $200$ in-hand grasps into the simulator, roll out each agent's own policy, and report the per-task rank-AUC of the learned value against the agent's own success, averaged over goals, along with mean counterfactual success rate. This is the value-quality measure used in the main text.}
\label{tab:cf_value}

\bottomrule

\end{table}

Figure~\ref{fig:cf_ladder} compares the learned value against a supervised linear readout from the representation that the value uses. 
This asks whether the representation contains linearly accessible information about the agent's own counterfactual success, and whether the learned scalar value preserves that information in its ranking.

The raw baseline is per-agent because counterfactual success depends on each policy, so the cleanest comparison is within method.}
