\section{Additional results}
\label{app:tables}

This appendix provides the detailed tables behind the main-paper figures: per-task success, the exact terminal-outcome distribution, the full dataset-support distances, the backward-embedding geometry probe, and the representation/value-ranking diagnostics. 
We distinguish two kinds of representation probes: offline reach-before-end separability, which asks whether features separate states from successful versus failed offline trajectories, and counterfactual on-policy ranking, which asks whether the learned value ranks in-hand states by the agent's own future success.

\subsection{Offline representation separability}
\label{app:offline_repsep}

This diagnostic asks whether learned representations linearly separate in-hand states from offline trajectories that later reach the goal from those that do not. 
The label is the play-data reach-before-end flag, not the agent's own counterfactual outcome. 
We therefore use this probe only to assess offline representation separability, not value quality.

\begin{table}[H]
\centering
\caption{Raw-state linear baseline: per-task linear-probe AUC from raw state sub-vectors using the offline reach-before-end label. The instantaneous configuration only weakly determines the offline outcome, and the gripper-only features are at chance.}
\label{tab:repsep_raw}
\begin{tabular}{lcc}
\toprule
\textbf{Raw feature subset} & \textbf{dims} & \textbf{AUC} \\
\midrule
Gripper (opening + contact) & $2$  & $0.50$ \\
Gripper + arm joints        & $14$ & $0.61$ \\
Full state                  & $28$ & $0.64$ \\
\bottomrule
\end{tabular}
\end{table}

For \fb{} and \rldp{}, the successor-style representation stack does not improve separability over the raw full-state linear baseline under this offline label. 
More importantly, the scalar value $Q=F\cdot z$ is near chance for this offline trajectory-level label. 
This offline probe should not be confused with the on-policy value-ranking test in Section~\ref{app:counterfactual_ranking}, which uses the agent's own counterfactual success as the target.

\subsection{Counterfactual value and representation ranking}
\label{app:counterfactual_ranking}

The main value-quality diagnostic uses an on-policy counterfactual label. 
We reset the simulator to in-hand grasp states, roll out each agent's own policy, and label each state by whether that agent reaches the goal. 
This directly tests whether the value the policy follows ranks post-acquisition states by their eventual tail outcome.

\begin{table}[H]
\centering
\caption{O\textbf{n-policy counterfactual value test.} We reset $200$ in-hand grasps into the simulator, roll out each agent's own policy, and report the per-task rank-AUC of the learned value against the agent's own success, averaged over goals, along with mean counterfactual success rate. This is the value-quality measure used in the main text.}
\label{tab:cf_value}
\begin{tabular}{lcc}
\toprule
\textbf{Method} & \textbf{Counterfactual value-AUC} & \textbf{Counterfactual success rate} \\
\midrule
\gciql{} & $0.89$ & $0.66$ \\
\crl{}   & $0.68$ & $0.38$ \\
\fb{}    & $0.61$ & $0.55$ \\
\rldp{}  & $0.52$ & $0.21$ \\
\bottomrule
\end{tabular}
\end{table}

Figure~\ref{fig:cf_ladder} compares the learned value against a supervised linear readout from the representation that the value uses. 
This asks whether the representation contains linearly accessible information about the agent's own counterfactual success, and whether the learned scalar value preserves that information in its ranking.
