\section{Preliminaries}

We consider a reward-free Markov decision process $(\Sspace,\Aspace,\Ptrans,\gamma)$ with state space $\Sspace$, action space $\Aspace$, transition kernel $\Ptrans$, and discount factor $\gamma$.
For a policy $\pi$, the successor measure from $(s,a)$ to a measurable set $X\subseteq\Sspace$ is:
\begin{equation}
    M^\pi(s,a,X) = \E_\pi\left[ \sum_{t\geq 0}\gamma^t \ind{s_{t+1}\in X} \mid s_0=s,a_0=a \right].
\end{equation}
When the state space is discrete, we write $M^\pi(s,a,s^+)$ for the discounted occupancy of state $s^+$.
For a state reward $r$, policy evaluation can be written as:
\begin{equation}
    Q^{\pi}_r(s,a) = \int_{\Sspace} M^\pi(s,a,ds^+) r(s^+).
\end{equation}
This identity motivates successor measures for URL: a reward-independent representation of future occupancy can be combined with a downstream reward to evaluate task-specific policies~\citep{dayan-nc93a,touati-neurips21a,touati-iclr23a,agarwal-rlj25a}.

Representing exact successor measures is intractable in large or continuous state spaces, particularly when the representation must cover many policies. Practical URL methods therefore impose additional structure.
For example, \fb{} uses a low-rank approximation:
\begin{equation}
    M^{\pi_z}(s,a,ds^+) \approx F(s,a,z)^\top B(s^+)\,\rho(ds^+),
\end{equation}
where $\rho$ is a reference state distribution and $z$ indexes a reward or policy embedding~\citep{touati-neurips21a,touati-iclr23a}.
Other methods can be viewed as learning lower-dimensional or goal-specific projections of future occupancy~\citep{agarwal-rlj25a}.
Goal-conditioned methods learn values or policies indexed by a target, 
contrastive methods learn state–goal scores, and predictive methods learn latent transition structure intended to support long-horizon control~\citep{eysenbach-iclr21a,eysenbach-neurips22a,ma-neurips22a}.
Each objective therefore determines which state distinctions are preserved for downstream control.

\subsection{Successor-measure view of the evaluated methods}
\label{sec:url_objectives_as_sm}

Let $o_G(s)$ denote the task-relevant goal coordinates extracted from state $s$.
For a goal $g$, define the success set
\begin{equation}
    G(g) = \left\{ s^+ : \left\|o_G(s^+) - g\right\| \leq \epsilon_G \right\}.
\end{equation}
The corresponding goal-relevant successor mass is
\begin{equation}
    m^\pi_g(s,a) = M^\pi\!\left(s,a,G(g)\right).
\end{equation}
This quantity measures the discounted future occupancy of the goal set under $\pi$.
We use $m^\pi_g$ only as a common reference: the evaluated methods do not all estimate it explicitly.

Under this view, \gciql{} learns a goal-conditioned value $Q(s,a,g)$~\citep{park-iclr25a},
while \crl{} learns a bilinear state-action-goal score $f(s,a)^\top b(g)$~\citep{eysenbach-neurips22a}.
\fb{} directly learns a low-rank factorization of policy-conditioned successor measures~\citep{touati-neurips21a,touati-iclr23a},
and \psm{} learns a basis for representing a family of successor measures~\citep{agarwal-arxiv25a}.
\rldp{} instead learns predictive features from which downstream task-conditioned policies are extracted~\citep{jajoo-iclr26a}.

Contact-rich manipulation can violate the assumption that geometrically similar states have similar futures.
Nearby robot-object configurations may correspond to a stable grasp, an incipient slip, or a loss of control, and can therefore induce substantially different future occupancies.
A useful learned representation or score must consequently preserve distinctions between interaction-states that affect future control, in addition to the coarse geometry of the robot, object, and goal.
