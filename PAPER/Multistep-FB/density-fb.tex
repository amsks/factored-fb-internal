\section{Setting}
\label{sec:prelim}

The successor measure of a policy $\pi$ is its discounted future-state occupancy,
\begin{equation}
\label{eq:sm}
M^\pi(s,a,X) = \E_\pi\!\left[ \sum_{t\ge0}\gamma^t \ind{s_{t+1}\in X} \;\middle|\; s_0=s,a_0=a \right], \qquad Q_r^\pi(s,a) = \int r(x)\,dM^\pi(s,a,x),
\end{equation}
so one learned measure evaluates any downstream reward
\citep{dayan1993improving,blier2021learning}.

Forward-backward (FB) representations
\citep{touati2021learning,touati2023does}
factorize the density of this measure against the dataset marginal $\rho$,
\begin{equation}
m_z(s,a,x) = F(s,a,z)^\top B(x),
\end{equation}
where $F$ represents the current state and action and $B$ represents a candidate future state.
FB embeds a reward as
\begin{equation}
z_r \propto \E_{x\sim\rho}[r(x)B(x)]
\end{equation}
and extracts values as
\begin{equation}
Q_r(s,a) \approx F(s,a,z_r)^\top z_r.
\end{equation}

The standard FB estimator is
\begin{equation}
\label{eq:fb-loss}
\mathcal L_{\mathrm{FB}} = \tfrac12 \E_{x\sim\rho} \left[ \left( m_z(s,a,x) - \gamma\bar m_z(s^+,a^+,x) \right)^2 \right]
                            - \E\left[ m_z(s,a,s^+) - \gamma\bar m_z(s^+,a^+,s^+) \right]
                            + \lambda_{\mathrm{ortho}} \mathcal L_{\mathrm{ortho}},
\end{equation}
where $a^+$ is sampled from the policy associated with $z$.
Random future-state queries receive the squared Bellman residual, while the observed successor supplies the immediate positive term.

\section{Why manipulation play stresses the FB estimator}
\label{sec:play}

To see the problem, it helps to separate the two parts of Equation~\ref{eq:fb-loss}.
For a random future-state query $x\sim\rho$, the quadratic term
\begin{equation}
\frac12
\E_{x\sim\rho}
\left[
    \left(
        m_z(s,a,x)
        -
        \gamma\bar m_z(s^+,a^+,x)
    \right)^2
\right]
\end{equation}
fits the bootstrapped successor density.
The second term supplies the observed one-step successor,
\begin{equation}
-
\E\left[
    m_z(s,a,s^+)
    -
    \gamma\bar m_z(s^+,a^+,s^+)
\right].
\end{equation}
Thus every transition gives a positive update at its realized successor.

This becomes problematic in manipulation play.
The robot may continue acting for many steps while the goal-relevant object (e.g. the cube) does not move: approach, grasp, transport, release, then rest.
On \texttt{cube-single-play-v0}, the cube is stationary on $48\%$ of transitions and stationary runs have median length $44$ steps.
On \texttt{cube-double}, each cube is stationary on $72\%$ of transitions; on \texttt{scene}, the drawer and window are stationary on $91\%$ and the buttons on $99.6\%$.

Consider a stationary run of length $L$.
The same object configuration appears as the observed successor on all $L$ transitions, so the FB objective receives $L$ nearly identical positive updates there.
The transition that moved the object into that configuration appears only once.
At the median run length of $44$ steps, \emph{the stationary configuration therefore influences the observed-successor term roughly forty times more often than the transition that brought the object there.}

The successor measure should assign mass to these stationary visits.
The problem is how FB represents that mass, specifically by predicting
\begin{equation}
    m_z(s,a,x)=F(s,a,z)^\top B(x)
\end{equation}
which is an unconstrained scalar density.
The true successor measure, however, has fixed total mass
\begin{equation}
M^\pi(s,a,\mathcal X) = \sum_{t\ge0}\gamma^t = \frac{1}{1-\gamma}.
\end{equation}
This constraint is not enforced by the bilinear prediction itself.
Repeated positive updates at persistent configurations can therefore be expressed by increasing critic scale rather than only by reallocating a fixed amount of future occupancy.
This is the failure mode we target.

\section{\DensityFB: normalized successor learning}
\label{sec:method}

\subsection{What is being predicted}

Write \( (s,a,s^+) \) for a transition from the offline dataset, and define
\begin{equation}
x=\phi(s), \qquad x^+=\phi(s^+)
\end{equation}
as the state variables whose future occupancy we want to predict.

The forward and backward representations see different inputs:
\begin{equation}
\label{eq:fb-args}
F(s,a,g)\in\mathbb R^d, \qquad B(x)\in\mathbb R^d.
\end{equation}
$F$ receives the full current state and action, while $B$ represents a candidate future configuration.

In our manipulation experiments, $\phi$ extracts the object coordinates.
We therefore condition on the full state but predict future occupancy over the goal-relevant object configuration.
This is the pushforward of the full-state successor measure and is sufficient for any reward defined only on those coordinates.
Setting $\phi$ to the identity instead gives $x=s$ and asks $B$ to represent the full state; we are testing this separately.

\subsection{From a successor measure to a probability distribution}

For a goal-conditioned policy $\pi_g(a\mid s)$, define the successor measure over $x$ as
\begin{equation}
    M^{\pi_g}(s,a,X) = \E_{\pi_g} \left[ \sum_{t\ge0} \gamma^t \ind{x_{t+1}\in X} \;\middle|\; s_0=s,a_0=a \right].
\end{equation}
Its total mass is
\begin{equation}
    M^{\pi_g}(s,a,\mathcal X) = \frac{1}{1-\gamma},
\end{equation}
independent of $(s,a,g)$.

We therefore normalize it:
\begin{equation}
\label{eq:normalized-sm}
    \nu^{\pi_g}(\cdot\mid s,a) = (1-\gamma) M^{\pi_g}(s,a,\cdot).
\end{equation}
Now
\begin{equation}
\nu^{\pi_g}(\mathcal X\mid s,a)=1.
\end{equation}

This normalization only rescales the usual successor-measure Bellman equation.

\begin{align}
    M^{\pi_g}(\cdot\mid s,a)    &= P_\phi(\cdot\mid s,a) + \gamma\,\E_{s^+,a^+} \left[ M^{\pi_g}(\cdot\mid s^+,a^+) \right], \\
    \nu^{\pi_g}(\cdot\mid s,a)  &= (1-\gamma)P_\phi(\cdot\mid s,a) + \gamma\,\E_{s^+,a^+} \left[ \nu^{\pi_g}(\cdot\mid s^+,a^+) \right],
\label{eq:normalized-bellman}
\end{align}
where the second line follows by multiplying the first by $1-\gamma$ and using $\nu=(1-\gamma)M$.
Thus the factor $1-\gamma$ appears only in the immediate term because we normalize the measure to unit mass; the recursive coefficient remains $\gamma$.
Consequently, for any $\nu_1,\nu_2$, the immediate term cancels and
\begin{equation}
    \|\mathcal T\nu_1-\mathcal T\nu_2\|_{\mathrm{TV}} \le \gamma\|\nu_1-\nu_2\|_{\mathrm{TV}},
\end{equation}
so the normalized Bellman operator has the same $\gamma$-contraction as the original successor-measure operator.

\subsection{Normalize the FB scores}

For a minibatch $\{(s_i,a_i,s_i^+)\}_{i=1}^n,$ we construct a query set from its observed successors (the cube positions)
\begin{equation}
U = \{u_j\}_{j=1}^n, \qquad u_j=\phi(s_j^+).
\end{equation}

For transition $i$ and candidate future configuration $u_j$, we compute
\begin{equation}
\ell_{ij} = \frac{ F(s_i,a_i,g_i)^\top B(u_j) }{\tau}.
\end{equation}
Standard FB interprets the bilinear quantity directly as a density.
\DensityFB{} instead treats it as a logit and normalizes across candidate successors:
\begin{equation}
\label{eq:density-softmax}
p_{ij} = \frac{ \exp(\ell_{ij}) }{ \sum_{k=1}^n \exp(\ell_{ik})}.
\end{equation}
Hence
\begin{equation}
p_{ij}\ge0, \qquad \sum_j p_{ij}=1.
\end{equation}

The vector $p_i$ represents the normalized future occupancy
$\nu^{\pi_{g_i}}(\cdot\mid s_i,a_i)$ on the sampled query set $U$.
The query set is redrawn on every update, so its size is a Monte-Carlo sample size.

\subsection{The hard Bellman target}

Equation~\ref{eq:normalized-bellman} gives the exact measure-level recursion.
For a sampled transition, the observed $x_i^+$ provides a sample from the immediate distribution $P_\phi(\cdot\mid s_i,a_i)$.
Because every batch successor is included in $U$, row $i$'s observed successor occupies slot $i$.

Define the one-hot vector
\begin{equation}
    e_{ij} = \ind{j=i}.
\end{equation}

Next, sample
\begin{equation}
a_i^+
\sim
\pi_{\bar\omega}(\cdot\mid s_i^+,g_i)
\end{equation}
and let $\bar p_i^+$ be the target-network prediction from $(s_i^+,a_i^+,g_i)$ evaluated over the same query set $U$.

The sampled Bellman target is then
\begin{equation}
\label{eq:hard-target}
    p_i^{\mathrm{tgt}} = \sg\left[ (1-\gamma)e_i + \gamma\bar p_i^+ \right].
\end{equation}
Both $e_i$ and $\bar p_i^+$ have unit mass, so
\begin{equation}
    \sum_j p_{ij}^{\mathrm{tgt}} = (1-\gamma)+\gamma = 1.
\end{equation}

We fit the predicted occupancy to this target with cross-entropy:
\begin{equation}
\label{eq:density-loss}
\mathcal L_{\mathrm{DensityFB}} = - \frac1n \sum_{i=1}^n \sum_{j=1}^n p_{ij}^{\mathrm{tgt}} \log p_{ij}.
\end{equation}

The update has a simple interpretation.
The observed successor receives $1-\gamma$ of the normalized occupancy, while the remaining $\gamma$ is inherited from the predicted occupancy after the next state.
Equations~\ref{eq:density-softmax}--\ref{eq:density-loss} define hard \DensityFB{}.

\subsection{What changed relative to FB?}

Hard \DensityFB{} keeps the forward--backward factorization and the policy-conditioned Bellman bootstrap.
The main change is how successor occupancy is represented.
Standard FB interprets $F(s,a,z)^\top B(x)$ directly as an unconstrained successor density.
\DensityFB{} instead treats the same bilinear quantity as a score and normalizes the scores across sampled successor queries:
\begin{equation}
    p_{ij} = \operatorname{softmax}_j \left( F(s_i,a_i,g_i)^\top B(u_j)/\tau \right).
\end{equation}
This makes the represented object the normalized successor measure $\nu=(1-\gamma)M$, whose sampled Bellman target is 
\begin{equation}
p_i^{\mathrm{tgt}} = (1-\gamma)e_i+\gamma\bar p_i^+.
\end{equation}

Two estimator choices accompany this change.
First, we fit the distributional target with cross-entropy rather than FB's squared/linear density estimator.
Second, the query set is built from batch successors, guaranteeing that the observed successor appears in the support of the immediate one-hot target.

We also remove FB's orthonormalization objective.
The softmax does not make $B$ orthogonal; rather, $F^\top B$ is no longer a calibrated density.
Only the resulting probabilities have predictive meaning, and downstream reward evaluation is performed directly under this distribution.
We therefore do not impose an orthonormal constraint on $B$.

\subsection{Why normalization addresses stationary play}

Normalization does not delete dwell occupancy.
If the cube remains stationary for many transitions, the learned distribution can still assign high probability to that configuration.
What it cannot do is increase its total mass:
\begin{equation}
    \sum_j p_{ij}=1.
\end{equation}
Repeated stationary transitions can therefore change where the predicted occupancy is allocated, but they cannot increase critic scale simply because the same successor appears many times.
This preserves the fact that the cube tends to remain where it was left while removing scale as a degree of freedom.

\subsection{Soft immediate targets}

Hard \DensityFB{} places the immediate $1-\gamma$ mass exactly on the observed successor.
We also evaluate a smoothed version.

Define normalized kernel weights
\begin{equation}
k_{ij}^{\epsilon} = \frac{ \exp\!\left( -\frac12 \|(u_j-x_i^+)/\epsilon\|^2 \right)}{ \sum_m \exp\!\left( -\frac12 \|(u_m-x_i^+)/\epsilon\|^2 \right)
}.
\end{equation}
Soft \DensityFB{} changes only the immediate term:
\begin{equation}
\label{eq:soft-target}
    p_{i,\mathrm{soft}}^{\mathrm{tgt}} = \sg\left[ (1-\gamma)k_i^\epsilon + \gamma\bar p_i^+\right].
\end{equation}

Everything else is unchanged.
The hard variant learns the normalized successor measure itself, whereas the soft variant smooths each one-step successor over an $\epsilon$-neighborhood before propagating occupancy.

\subsection{Role of the goal}

Goal conditioning is not required by the \DensityFB{} estimator.
We use $g$ because hindsight relabeling supplies goals from the play data, allowing us to learn a family of goal-conditioned policies $\{\pi_g\}$ and their corresponding successor measures.
In this sense, $g$ plays the same indexing role that the latent task vector $z$ plays in standard FB, and training still requires no reward labels or task labels.

\subsection{Control}

The policy-extraction recipe is unchanged from the corresponding baseline.
The only difference is the critic supplied to the actor.
A standard critic returns a scalar $Q(s,a,g)$ directly; \DensityFB{} returns a distribution over candidate future configurations, so we first read a scalar
goal value from that distribution.

For either hard or soft \DensityFB{}, define the goal readout
\begin{equation} 
    h_g^\epsilon(u_j) \propto \exp\!\left( -\frac12 \|(u_j-g)/\epsilon\|^2 \right), \qquad \sum_j h_g^\epsilon(u_j)=1.
\end{equation}
The scalar critic supplied to the actor is
\begin{equation}
\label{eq:goal-readout}
    q_g(s,a) = \sum_j p_j(s,a,g)\, h_g^\epsilon(u_j).
\end{equation}
The same goal readout is used for both training variants.
Hard versus soft refers only to the immediate term of the successor-measure
Bellman target, not to the actor or its goal weighting.

The occupancy model and the goal used to train the actor are separate objects.
For a goal $g$, the actor scores actions by the predicted occupancy near the goal, using the same normalized kernel weights as the soft immediate target, evaluated at the goal:
\begin{equation}
\label{eq:goal-readout}
q_g(s,a) = \sum_j p_j(s,a,g)\, k_j^\epsilon(g),
\end{equation}
with $k^\epsilon$ from Equation~\ref{eq:soft-target}'s kernel and the per-block tolerances for multi-object goals.
The kernel weighting is used by both training variants; the hard/soft choice affects only the immediate term of the measure loss, never the actor's goal weighting.

For the flow actor, we use this inside the behavior-regularized objective
\begin{equation}
\label{eq:actor}
    \mathcal L_\pi = \lambda_{\mathrm{BC}} \mathcal L_{\mathrm{BC\text{-}flow}} - \E\left[ \frac{ q_g(s,\pi(s,g)) }{s_q} \right],
\end{equation}
where
\begin{equation}
    s_q = \E\left[ \left| q_g-\E[q_g] \right| \right], \qquad \lambda_{\mathrm{BC}}=3.
\end{equation}
The predicted occupancy contains a large action-independent component, whereas the actor only needs differences between actions.
We therefore center $q_g$ before computing its magnitude normalizer.
The behavior-cloning baseline trains the same actor with the $q_g$ term removed.
We separately evaluate Gaussian DDPG+BC as an alternative policy extractor.

\subsection{One training step}
Algorithm~\ref{alg:densityfb} summarizes one \DensityFB{} update.

\begin{algorithm}[t]
\caption{
\DensityFB{}, one gradient step.
{\color{fbdiff}Blue} marks changes to the successor-measure estimator relative to standard FB.
{\color{hardvar}Teal}/{\color{softvar}orange} marks the hard/soft immediate-target choice.
Goal conditioning, the choice of $\phi$, and policy extraction are experimental setup choices and are left black.
}
\label{alg:densityfb}
\begin{algorithmic}[1]

    \State Sample transitions $\{(s_i,a_i,s_i^+)\}_{i=1}^{n}$ and hindsight goals $\{g_i\}_{i=1}^{n}$
    \State Set $x_i^+=\phi(s_i^+)$
    \State {\color{fbdiff} Build the query support $U=\{u_j=x_j^+\}_{j=1}^{n}$} \Comment{{\color{fbdiff}FB samples queries $x\sim\rho$}}
    \State Compute bilinear scores $c_{ij}=F(s_i,a_i,g_i)^\top B(u_j)$
    \State {\color{fbdiff} Normalize $p_{ij} = \operatorname{softmax}_j(c_{ij}/\tau)$} \Comment{{\color{fbdiff}FB treats $F^\top B$ as a density}}
    \State Sample bootstrap actions $a_i^+ \sim \pi_{\bar\omega}(\cdot\mid s_i^+,g_i)$
    \State Evaluate target-network occupancies $\bar p_i^+$ over the same query support $U$
    \State {\color{hardvar} Hard: $\eta_i=e_i$, where $e_{ij}=\ind{j=i}$} \Comment{{\color{softvar}Soft: $\eta_i=k_i^\epsilon$}}
    \State {\color{fbdiff} Form $p_i^{\mathrm{tgt}} = \sg\!\left[ (1-\gamma)\eta_i + \gamma\bar p_i^+ \right]$} \Comment{{\color{fbdiff}normalized Bellman target}}
    \State {\color{fbdiff} Update $F,B$ with $-\frac1n \sum_i\sum_j p_{ij}^{\mathrm{tgt}} \log p_{ij}$} \Comment{{\color{fbdiff}FB: squared/linear loss $+$ ortho}} 
    \State Update the actor using $q_g$ from Equation~\ref{eq:goal-readout}, with $F,B$ frozen \Comment{same extractor as baseline}
    \State Soft-update the target networks

\end{algorithmic}
\end{algorithm}

\label{sec:main-results}

We evaluate on state-based OGBench manipulation and locomotion
\citep{park2024ogbench}.
All of our models are trained for $500$k gradient steps with no reward labels.
Native evaluation uses five tasks, $50$ episodes each, and three seeds; intervals are $95\%$ $t$-based confidence intervals.

We evaluate each representation with two actor extractors, FQL + BC and Gaussian DDPG+BC, to separate representation quality from policy extraction.

Published GCIQL results use $1$M gradient steps and eight seeds.

\paragraph{Manipulation results are similar under DDPG+BC.}
Switching from FQL + BC to DDPG+BC lowers soft \DensityFB{} from $0.929$ to $0.879$ on \texttt{cube-single} and from $0.736$ to $0.652$ on \texttt{cube-double}.
The improvement is therefore not specific to the flow actor.
On \texttt{antmaze-medium}, the same switch moves \DensityFB{} from $0.563$ to $0.829$, so actor extraction matters much more there.

\paragraph{\DensityFB{} does not improve AntMaze.}
\texttt{antmaze-medium} removes the structure that motivated \DensityFB{}: the goal-relevant variable is the agent itself, so there is no manipulated object that remains stationary while actions continue.
Under DDPG+BC, \DensityFB{} reaches $0.829$ against $0.837$ for our matched GCIQL control, and both remain below the strongest published method on that benchmark ($0.96$ for HIQL).
This supports the narrower hypothesis that \DensityFB{} helps when play data contains long stationary segments in the goal-relevant object variables.

\section{Reward evaluation}
\label{sec:reward-transfer}

Goal reaching only tests whether the learned measure supports the benchmark goals.
Reward transfer asks whether the same measure can evaluate a reward that was never used for training.

At test time, we draw a pool $U_P=\{u_j\}_{j=1}^{16{,}384}$ of object configurations from the dataset.
For a given $(s,a,g)$, we compute the normalized occupancy $p(s,a,g;U_P)$ over this pool and evaluate the reward once on every pool element.
The direct Monte-Carlo readout is
\begin{equation}
    \frac{ p(s,a,g;U_P)^\top r(U_P) }{ 1-\gamma}.
\end{equation}

Because stationary transitions concentrate predicted occupancy near the current object configuration, finite-pool smoothing matters most there.
We therefore apply a local correction at $x=\phi(s).$

Let $ c_x\in\Delta^{|U_P|-1}$ denote the normalized kernel weights of $x$ over the pool (the same $k^\epsilon$ as Equation~\ref{eq:goal-readout}).
We replace the interpolated reward $c_x^\top r(U_P)$ with its exact value $r(x)$:
\begin{equation}
\label{eq:density-readout}
    \widehat Q_r(s,a,g) = \frac{ r(x) + \left( p(s,a,g;U_P)-c_x \right)^\top r(U_P)}{1-\gamma}.
\end{equation}
The correction is action independent, so it changes calibration without changing the ranking of actions.
The resulting readout remains linear in $r$ and requires no retraining.

To act under a new reward, we score candidate goals using Equation~\ref{eq:density-readout}, select the highest-valued goal from the initial state, and execute its goal-conditioned policy.
This replaces FB's analytic reward-to-$z$ mapping with search over the learned goal-conditioned policy family.

\paragraph{Reward construction.}
We test three reward families, all defined only from object coordinates, valued in $[0,1]$, and never observed during training (Figure~\ref{fig:rewardfams}; internal names \texttt{dirac}/\texttt{dense}/\texttt{region}):

\emph{sparse}, the benchmark tolerance indicator
\begin{equation}
    r(x) = \ind{\|x-g\|\le\epsilon},
\end{equation}
conjunctive over object blocks, at the five task goals;

\emph{dense}, the same centers with distance-based shaping
\begin{equation}
    r(x) = \exp(-d(x,g)/2\epsilon)
\end{equation}
in tolerance-scaled coordinates;
and \emph{held-out regions}, the same sparse indicator centered at reachable dataset configurations that are not benchmark goals.
These centers are drawn by hindsight from within episodes and kept only when at least five relabeled samples fall inside the region.
Dense versus sparse varies reward shaping while keeping the goal fixed.
Sparse versus held-out regions keeps the reward form fixed while changing where in object space the reward is located.
We evaluate $25$ episodes per task and three seeds.
The fixed-partition ablation replaces the resampled query set with $256$ fixed prototypes while leaving the rest of the objective unchanged.

\paragraph{Comparison with published zero-shot methods.}
Table~\ref{tab:published} places our sparse-reward results alongside published state-based OGBench results from \citet{bagatella-iclr26a}.
This is not a controlled comparison.
The published results use $1$M gradient steps, $10$ seeds, and $10$ evaluation episodes per task, whereas ours use $500$k steps, three seeds, and $25$ episodes.
The task-index inference also differs: their methods use linear regression on relabeled data, whereas \DensityFB{} searches over candidate goals.
Our matched plain-FB column partially validates itself against that table: it reproduces the published FB result on \texttt{cube-single} ($0.536$ local vs $49.6$ published) and the \texttt{cube-double} floor (${\le}0.056$ vs $2.6$), but on \texttt{scene} our FB reaches ${\sim}0.45$ against a published $12.8$, so the published scene FB number should not be used as a comparison point for this stack; the matched local baseline is the honest one.
A related observation from the same probes: on \texttt{scene}, plain FB's reward interface outperforms its own goal conditioning ($0.45$ via $z_r$ vs $0.14$ native), so FB's weakness there is its goal encoding rather than its reward inference.

\section{Open items}
\label{sec:todo}

The following are not yet done, and the claims above should be read with them in mind.

\paragraph{Matched-protocol baselines.}
Every published number in Table~\ref{tab:published} is quoted rather than re-run.
A controlled comparison requires rerunning these methods with the same training budget, seeds, evaluation episodes, and task-index inference.
Until that is done, the table shows our numbers next to published ones rather than a controlled comparison.
We have re-run FB from the same codebase on \texttt{cube-single}; the remaining environments and methods have not yet been checked this way.

\paragraph{Seed parity.}
Our cells use three seeds against ten in the published results, which is why several of our confidence intervals are wider than the differences they bracket.
The \texttt{cube-single} comparison in Table~\ref{tab:published} lies inside our interval and should not be read as a separation until the seed count matches.

\paragraph{Cells still outstanding.}
Only one cell is missing: plain FB with the DDPG+BC actor on \texttt{antmaze-medium}, whose launch failed because the AntMaze dataset was absent from the expected path. This is a missing run rather than a slow one.

\paragraph{Full-state successor ablation.}
Our main manipulation experiments predict occupancy over object coordinates, $x=\phi(s)$.
We are also testing $\phi(s)=s$, where the backward representation receives the full next state.
This will separate the effect of normalized successor learning from the choice to predict only the goal-relevant state factor.

\paragraph{Separating normalization from the fitting loss.}
The current method combines a softmax-normalized successor representation with a cross-entropy Bellman loss.
A useful ablation is to keep the same normalized Bellman target
\begin{equation}
p_i^{\mathrm{tgt}}
=
(1-\gamma)e_i+\gamma\bar p_i^+
\end{equation}
but fit it with squared error instead of cross-entropy.
If both objectives behave similarly, the main effect comes from normalization; if not, the fitting loss is part of the improvement.

\paragraph{Orthonormality.}
Equation~\ref{eq:fb-loss} includes the orthonormality term used by standard FB; \DensityFB{} removes it entirely.
No orthonormality, mass, or non-negativity penalty appears anywhere in the implementation (the configuration layer refuses them), because the softmax supplies the normalization those terms approximate.
This is deliberate: with a frozen capable representation, orthonormality bounds the critic scale but caps success at $0.225$.

\paragraph{Separating readout error from goal-selection error.}
The gap between goal reaching and reward transfer on \texttt{cube-double} currently combines errors from reward integration and goal selection.
Comparing the retrieved goal against an oracle that selects the reward center directly would separate the two.
