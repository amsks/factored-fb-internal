# Didactic-2: bilinear square-loss objective

This figure uses the verified four-state deterministic path counterexample, drawn
as a doorway bottleneck. State `s_1` is the gateway: taking `right` from the
outside state `s_0` enters it, and every downstream state (`s_2,s_3`) is reachable
only after that crossing. Taking `left` leaves the agent outside. The same
rank-two spherical/whitened class contains a representation with the correct
start-state action and a representation with the wrong action. The global
unweighted bilinear square objective has a feasible wrong-control value
(`0.0806398`) below the feasible correct-control witness (`0.1699654`), and the
exact certificate proves that every global optimum has a negative start gap.
Thus the example is not a capacity or feature-normalization failure: it is
objective selection at a control bottleneck. The square-loss-selected model
assigns the wrong ordering to the gateway action, so the downstream region is
never reliably unlocked.

The lower panel gives an explicit rank-two-logit categorical successor
candidate. It assigns the goal state probability `0.359` after taking right
from `s_0`, versus `0.275` after taking left, so it preserves the correct
control ordering. The candidate is also compatible with the same spherical
and whitened backward-feature constraints. This is a geometry comparison:
the categorical construction can retain the local goal peak while the
bilinear linear prediction is selected by its global square objective for
the wrong ordering. Cross-entropy is the natural loss for that categorical
model, but this graph should not be described as proving that cross-entropy
alone is necessary; squared loss on the same softmax family also preserves
the ordering.

The exact certificate is documented in
`docs/notes/2026-09-11-deterministic-path-spherical-counterexample.md` and
verified by `scripts/didactic/verify_deterministic_path_spherical.py`.

The tabular check is `verify_tabular.py`; it reruns the exact certificate and
also records the existing full-expectation TD check on the same path in
`tabular_verification.json`. In that TD check, four of six spherical-FB runs
have negative start gaps (the other two converge to a different correct-control
stationary solution), while all six density runs have positive start gaps.
This is empirical TD evidence; the exact global certificate is stronger and is
separate from finite-time target-network convergence.

Generate the assets with:

```bash
python draw.py
python verify_tabular.py
```

The standalone spatial graph is generated by `spatial_bottleneck_mdp.py`:
`spatial_bottleneck_mdp.{png,pdf,svg}`. It uses only five states: two states on
the left, the central bottleneck `b`, and two states on the right. The only
crossing is the deterministic `cross` action at `b`; `fail` returns to the left
and `wait` stays at `b`. The drawing keeps the spatial arrangement without
adding room boxes or unnecessary states.
